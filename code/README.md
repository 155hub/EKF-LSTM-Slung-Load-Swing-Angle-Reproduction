# EKF-LSTM 吊载摆角估计代码包

本文件包保存本次复现实验实际使用的脚本、仓库核心算法文件和必要仿真配置，不包含Python虚拟环境、CUDA、ROS、PX4或Gazebo安装文件。

## 目录结构

### `01_本次复现实验脚本`

- `轨迹协议.py`：生成单轴、椭圆、Lissajous、间歇和扫频水平位置轨迹。
- `采集多轨迹飞行.py`：通过ROS/MAVROS/PX4 SITL采集IMU、位姿、推力和Gazebo真值。
- `批量采集.py`：生成确定性轨迹配置并批量启动仿真采集。
- `执行全流程.py`、`恢复采集并训练.py`：组织采集、恢复和仅新数据训练流程。
- `训练与统一测试.py`：回放CSV、运行仓库EKF、构造400点滑动窗口、训练LSTM并统一评估。
- `混合训练与复测.py`、`启动混合训练.py`：将仓库原训练集与10次新训练飞行混合，从头训练并复测。
- `仅测试混合第33轮.py`：冻结第33轮检查点，只运行测试，不更新权重和归一化参数。

### `02_仓库核心算法`

- `吊载扩展卡尔曼滤波.py`：仓库SlungLoadEKF实现。
- `LSTM修正模型.py`：13维输入、2层64单元LSTM修正网络。
- `离线效果验证.py`：CSV回放、懒加载滑动窗口、模型加载、训练和指标计算的公共实现。

### `03_轨迹配置`

保存10次训练、4次验证和4次测试飞行的固定随机种子、轨迹顺序、幅值、频率、相位、方向和过渡时间。

### `04_仿真场景与模型`

- `仿真环境.sh`：启动PX4 SITL、Gazebo Classic和MAVROS的实验环境脚本。
- `吊载起飞场景.world`：本次采集使用的Gazebo场景。
- `iris_slung_load.sdf`、`model.config`：Iris吊载模型；吊物0.5 kg，吊绳几何长度2.0 m，吊绳质量0.05 kg。

## 运行环境与关键参数

- WSL2 Ubuntu 20.04
- PX4 SITL + Gazebo Classic + ROS/MAVROS
- 采样频率：50 Hz
- LSTM窗口长度：400点，即8秒
- 输入维度：13
- 网络结构：2层LSTM，每层64个隐藏单元
- 损失：前4个状态的普通MSE
- 随机种子：42

## 推荐阅读和运行顺序

1. 阅读`轨迹协议.py`和`03_轨迹配置`。
2. 使用`批量采集.py`与`采集多轨迹飞行.py`生成CSV。
3. 使用`训练与统一测试.py`完成仅新数据训练和测试。
4. 使用`混合训练与复测.py`完成仓库原数据与新数据的混合训练。
5. 使用`仅测试混合第33轮.py`冻结复测选定检查点。

## 注意事项

- 脚本中的部分路径仍以本次Windows/WSL目录结构为基准，迁移到其他计算机时需要调整根路径。
- 代码包不包含模型权重和数据；数据位于数据集包，结果位于结果包。
- 本轮目标是保持仓库算法规则，已记录的EKF雅可比与标签问题没有修改。
