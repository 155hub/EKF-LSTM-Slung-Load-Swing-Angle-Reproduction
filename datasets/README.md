# EKF-LSTM 吊载摆角估计数据集包

本文件包包含本次训练、模型选择和测试实际使用的CSV数据，以及每次新仿真飞行的JSON元数据。未收录失败采集、试飞数据、ULG飞控日志、回放缓存或逐窗口预测结果。

## 数据组成

### 仓库原数据

- `01_仓库原数据/训练集/吊载摆角训练数据集.csv`
- `01_仓库原数据/测试集/吊载摆角测试数据集.csv`

这两份CSV来自原EKF-LSTM仓库。原训练集加入混合训练；原测试集只在模型冻结后作为`repository_test`使用，不参与训练、归一化或模型选轮。仓库未提供与这两份合并CSV一一对应的完整轨迹配置，因此不能严格恢复每段飞行的期望路径和期望加速度。

### 新仿真数据

- `02_新仿真数据/训练集/`：10次完整飞行，用于LSTM权重更新和训练归一化。
- `02_新仿真数据/验证集/`：4次完整飞行，不反向传播，用于选择最佳检查点。
- `02_新仿真数据/测试集/`：4次完整飞行，仅在模型冻结后评估。

训练、验证和测试按完整飞行划分，不切分同一次飞行，也不允许400点滑动窗口跨越文件或时间重置边界。

## 新数据集的由来

新数据由WSL2 Ubuntu 20.04中的PX4 SITL、Gazebo Classic和ROS/MAVROS仿真生成。仿真使用仓库的`iris_slung_load`模型和本次固定的吊载起飞场景：

- 无人机主体质量：1.5 kg
- 吊物质量：0.5 kg
- 吊物尺寸：0.2 m × 0.2 m × 0.2 m
- 吊绳几何长度：2.0 m
- 吊绳质量：0.05 kg
- 采样频率：50 Hz
- 每次飞行时长：180秒，约9000行

每次飞行由12秒悬停、4段各36秒的水平轨迹和24秒末端悬停组成。训练集覆盖单轴、椭圆、Lissajous和间歇激励；`test_03`和`test_04`额外包含训练集中没有的扫频轨迹。不同飞行使用不同随机种子、幅值、频率、相位、方向和余弦过渡时间。

无人机位置轨迹通过MAVROS发送给PX4位置控制器。脚本不直接发送期望加速度；轨迹加速度由位置指令的二阶导数产生。新测试飞行的轨迹等效水平峰值加速度约为4.03、4.23、6.33和5.17 m/s²。

## CSV字段来源

- `timestamp`：仿真时间。
- `imu_ax`～`imu_az`、`imu_wx`～`imu_wz`：IMU线加速度和角速度。
- `drone_px`～`drone_pz`、`drone_vx`～`drone_vz`：无人机位置和速度。
- `drone_qw`～`drone_qz`：无人机姿态四元数。
- `cmd_thrust`：姿态目标消息中的归一化推力指令。
- `gt_xi`、`gt_zeta`及其角速度：由Gazebo中无人机和吊物相对位置投影得到的摆角真值。
- `gt_load_px`～`gt_load_pz`：Gazebo吊物位置真值。
- 新仿真CSV还保存时间戳、新鲜度、Gazebo无人机姿态和速度等同步检查字段。

每个新仿真CSV旁边的同名JSON记录飞行状态、完整轨迹参数、采样率、模型与场景摘要、行数以及CSV SHA-256，用于追溯数据来源。

## 数据隔离说明

- 10次训练飞行与4次测试飞行没有文件、时间片或滑动窗口重合。
- `test_01`和`test_02`与训练集共享轨迹家族，但参数不同。
- `test_03`和`test_04`包含训练未覆盖的扫频轨迹。
- 四次测试飞行已经被用于多次结果比较，因此不能继续作为新的完全盲测数据。

- `文件清单_SHA256.csv`记录本包交付文件的大小和摘要，可用于检查复制完整性。
