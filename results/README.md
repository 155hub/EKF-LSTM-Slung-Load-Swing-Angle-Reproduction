# EKF-LSTM 吊载摆角估计结果包

本文件包汇总本次仓库规则下的离线复现实验结果。

## 目录内容

- `01_训练曲线/`
  - `仅新数据模型_完整50轮_最佳第39轮.png`：只使用10次新仿真训练飞行，从头训练50轮，验证集选中第39轮。
  - `混合模型_实际35轮_最佳第33轮.png`：根据当时保存的第1～35轮`训练进度.json`补绘；没有重新训练或修改模型。仓库原训练集与10次新训练飞行混合，从头训练，验证集选中第33轮。
- `02_测试对比图/仅新数据模型/`：仅新数据模型在4次新测试飞行和仓库原测试集上的真值、EKF、EKF-LSTM对比图。
- `02_测试对比图/混合模型第33轮/`：混合第33轮模型在相同测试数据上的真值、EKF、EKF-LSTM对比图。
- `结果汇总.xlsx`：总体RMSE、分飞行详细指标、两次训练损失过程和数据划分。
- `文件清单_SHA256.csv`：本包所有交付文件的大小和SHA-256摘要。

## 主要结论

- 四次新测试飞行合并：EKF综合RMSE为1.8696°，仅新数据模型为0.8311°，混合第33轮模型为0.7044°。
- 仓库原测试集：仓库原模型为2.0929°，仅新数据模型为5.6994°，混合第33轮模型为2.1889°。
- 混合训练显著改善了新飞行数据上的估计效果，并基本恢复了仓库原测试集性能，但仍略逊于仓库原模型在原测试集上的2.0929°。
